Noto Sans KR 본문 글꼴 (굵기 400·700, normal) 자체 번들.
출처: npm 패키지 @fontsource/noto-sans-kr 5.3.1 (원본 Noto Sans KR, SIL OFL 1.1, LICENSE 참고).
만든 방법: `npm pack` 으로 받아 풀고, 400·700 normal 의 woff2 파일만 files/ 로 복사했다. 설치·스크립트 실행 없음.
noto-sans-kr.css 는 두 굵기의 @font-face 를 합친 것(woff2 만, 상대 경로, font-display: swap, unicode-range 원본 그대로).
