# 대국민 모드 시안 빌드 원본

`docs/design/대국민-모드-시안.html` 을 만드는 원본이다. 시안은 앱에 연결하지 않은 독립 HTML 이다.

```sh
cd tools/design/public-mock
python3 build_data.py data.json   # 저장소 자료(data/board/*.json)에서 색인·지도·일정 추출
node build.js                     # template.html + search.js + assets/js/map3d.js·assets/css/map3d.css(3D 지도 공용, /map 개요와 같은 구현) + data.json + app/globals.css 내보내기 층 → docs/design/대국민-모드-시안.html(데모판) + assets/citizen/index.html(운영판, /citizen)
node ../../../scripts/build.js    # 개발 서버가 보내는 public/ 사본 갱신
node search.test.js               # 검색·카드·라벨 시험
```
