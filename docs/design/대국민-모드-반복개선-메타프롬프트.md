# 대국민 모드 시안 — 디자인 품질 반복 개선 메타 프롬프트

이 문서는 대국민(국민) 모드 첫 화면 시안의 디자인 품질을 **평가 → 개선 → 재측정** 순서로 반복해 끌어올리는 실행 지시서다.

- 쓰는 법: Claude Code 에 이 파일을 통째로 주고 `이 메타 프롬프트대로 1회차를 진행해` 라고 말한다. 여러 회차를 맡길 때는 `/goal` 이나 `/loop` 에 같은 지시를 건다.
- 사용자가 정한 것을 바꾸려면 반드시 묻는다(아래 '바꾸지 않는 것').

## 2. 바꾸지 않는 것 (사용자 결정, 2026-10-16, 2026-10-17 v7 로 갱신)

- **모드:** 헤더의 다크/라이트 토글 옆에 [국민|담당자] 토글을 둔다. 처음 온 사람은 **국민 모드**로 시작하고, 선택은 localStorage 에 남긴다.
- **첫 화면:** 메인은 **검색창 + 내 위치 기반 지도 그림**이다.
  - 위치 권한 팝업 없이 IP 로 시도를 추천한다.
  - [현 위치]를 누르면 브라우저 안에서 시군구를 판정한다. 좌표는 기기 밖으로 보내지 않는다.
- **v7 요구 4가지 (2026-10-17):** ① 어렵지 않게 ② 무한 스크롤 없이 한 화면 요약 ③ 지도가 깨지지 않고 3D 로 한눈에 ④ 국민이 알고 싶은 내용(외부 상용 앱 참고).
- **한 화면 요약 (v7):**
  - 1440×900 첫 화면에 요약 카드와 지도 전체가 들어간다. 지도 세로는 표기 품질을 위해 늘려도 된다(2026-10-17 오후, 문서 ≤ 1.35 화면). 자세한 목록은 칸의 '전체 n' 으로 여는 옆 시트에 둔다.
  - 지도 카드 머리 줄에 **큰 지도(/map)로 가는 연결점**을 둔다(lib/board/map-href.ts 규칙: 시군구 `/map?sgg=`, 구 있는 시 `/map?sido=41&pick=`, 시도 `/map?sido=`).
  - 위 줄: 왼쪽 **요약 카드**(한 문장 + 들어올 해가 정해진 물량 + 가장 가까운 일정 + 상태 배지), 오른쪽 **3D 지도**.
  - 아래 줄: 같은 높이 칸 3개 — **일정**(모집 공고 우선 가까운 3건) / **언제 들어오나**(연도 막대 + 연도 미정) / **사업**(상위 3).
  - 390 은 세로로 쌓되 1.5 화면 이내, 자세한 것은 아래 시트.
- **3D 지도 (v7, 2026-10-17 사용자 지시로 기둥 → 면 높낮이):**
  - 개별 세로 기둥은 쓰지 않는다. **시군구 면 자체가 호수에 따라 솟되 극단적이지 않게**: 0호는 평평, 그 밖은 h = 3px + (Hmax − 3)·√(u/umax), Hmax 는 무대 높이의 약 4%(8~18px). 시도 안 배율 하나. 실제 비율(등방)을 지킨다.
  - 옆벽은 남쪽을 향한 변에만, 높이는 이웃과의 차. 높이 오름차순으로 벽 → 윗면 순서로 그린다(깨짐 방지).
  - 면 위에 **시군구 이름 / 호수('1.6만') 두 줄 묶음**을 적는다(2026-10-17 사용자 요청, 짧은 이름 '남양주'). 호수 큰 순으로 자리를 잡고 상위 5·보는 곳·내 동네는 반드시 보인다. 면 안에 안 들어가면 상위 10 까지 짧은 지시선, 그 밖은 이름만 또는 생략(순위 목록이 받음). 고른 곳·가리킨 곳은 같은 자리 묶음을 강조형으로 바꾼다(위치 고정). 이름이 보이는 면 비율 목표: 1440 경기·서울 ≥ 80%, 인천 100%.
  - 선: 지도에서 점선·빗금을 쓰지 않는다. 고른 곳은 실선 + 밝은 바깥선. 경계는 공유 호 단위로 다듬어(단순화 + Chaikin) 계단·잔지그재그 없이, 이웃끼리 틈·겹침 없이 그린다.
  - 면 색은 단계 구분도(--primary 계열 4단계)이고, 단계색 `--st-*` 는 6단계 전용이다.
- **없앤 것:** 시군구 전부를 줄 세운 비교 막대, 따로 있던 내 동네 카드, **지도 좌우 지시선 말풍선 카드(v7)**, **국민 모드 아래의 9구역(v7, 담당자 모드에만 둔다. 지우지 않는다)**. 다시 넣지 않는다.
- **숫자 정의:** 큰 숫자는 계획부터 모집까지 합계(아래 '표기')를 유지한다. 한 문장 바로 아래에 '이 중 n 집은 들어올 해가 정해졌어요'를 함께 적는다.
- **동작:** 보기와 내 동네 저장을 나눈다. 저장은 [내 동네로 정하기]·[현 위치]·[맞아요] 뒤 선택으로만 한다.
- **표기:**
  - 문구는 최소로 하고, 설명·출처·기준일은 툴팁에 둔다. '실데이터' 표지는 쓰지 않는다.
  - 숫자 정의는 하나다. 앞으로 들어올 집 = 리본 ①~④, 원장 단계 02~05. 큰 합계 = 지도 면 합 = 카드 = 지도 라벨 = 검색 숫자.
  - 표기 형식: 큰 합계는 '9만 9,896호', 비교 숫자는 '16,388호', 지도 라벨은 '1.6만' 이고 단위 '호'는 범례에 둔다.
- **버튼:** 보이는 높이 36px, 누르는 영역 44px(투명 확장).
- **하지 않는 것:** 광고·모달, 가격·조회수, 로그인 유도.
- **남겨 둔 원천 그대로의 것:** 안산–화성 등 물길 두 줄 경계와 인천 직선 구 경계는 원천이 그렇다. 수도권 밖은 '경계 준비 중'이 정상이다.

## 6. 설계 원칙 (이 화면에 맞춘 것)

- **국민의 질문 순서:** 내 동네에 → 언제 → 얼마나 → 어떤 사업. 화면의 위계는 이 순서를 따른다.
  - 가장 큰 글씨는 '가장 가까운 일정'이다. 모집 공고가 가까우면 모집 공고를 쓴다.
- **쉬운 말:** 단계 번호(①~④), 블록 기호(BL), D-day 는 국민 말로 바꾼다. 예: '계획부터 모집까지', '1블록', '346일 남음'. 정의는 ⓘ 에 둔다.
- **지도 라벨** (모범 사례 조사 결과):
  - 위치는 면 안에서 가장 넓은 곳(polylabel)으로 하고, 3D 윗면 높이에 붙인다. 글자는 세워서 쓴다.
  - 작은 면은 숨기거나 짧은 지시선으로 빼낸다.
  - 겹칠 때 우선순위는 보는 곳 > 내 동네 > 호수가 큰 순이다.
  - 진한 면에는 흰 글자 + 어두운 반투명 테두리, 옅은 면에는 진한 글자 + 밝은 테두리를 쓴다.
- **3D (v7):**
  - 기둥 시안(평평한 판 + 선형 기둥)은 사용자가 되돌렸다(2026-10-17). 면 높낮이로 하되 극단적이지 않게(√ 척도, Hmax 무대 높이 약 4%).
  - 고른 곳은 실선 고리·밝기로 강조하고 높이는 바꾸지 않는다(G15).
  - 장식 그림자보다 읽기를 앞에 둔다.
- **비교와 합계 (v7):** 지도 숫자만 보고 더하게 하지 않는다(NYT 선거 지도 교훈). 합계는 요약 카드가, 비교는 '많은 곳' 순위 목록이, 상세는 시트가 맡는다.
- **모바일:** 첫 화면에 검색, 다음 일정, 지도 윗부분이 함께 보이게 한다. 범례는 지도 바로 위에 두고, 엄지가 닿는 아래쪽에 주요 동작을 둔다.
- **어르신:** 본문 14~15px, 한 덩어리에 4개 이하, 굵은 숫자, 줄 간격을 넉넉히 한다.
- **신뢰:** 출처(건축HUB·LH·청약홈)와 기준일을 ⓘ 와 출처 띠에 둔다. 예정일이 바뀔 수 있다는 한 줄을 남긴다.
- **craft-floor 금지 사항을 지킨다.** 히어로 지표 틀 그대로 쓰기, 카드 속 카드, 장식용 무지개색, 의미 없는 움직임은 금지다.

## 7. 사용자에게 물어야 하는 경우

- 2절 결정을 바꿔야 결함이 풀릴 때. 예: 좌우 카드 6장이 인지 부하를 만든다고 평가될 때.
- 원천 자료 한계를 화면에서 덮어야 할 때. 예: 물길 두 줄 경계, 인천 직선 구 경계, 수도권 밖 경계.
- 점수 목표와 사용자 요구가 부딪칠 때. 이때는 사용자 요구를 따르고 그 사실을 보고에 적는다.
