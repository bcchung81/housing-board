## 1. 표준코드(법정동)

### 1.1 행정표준코드 법정동코드 API

| 항목 | 내용 | 확인 |
|---|---|---|
| 제공 | 행정안전부 행정표준코드 법정동코드(공공데이터포털) | 확인함 |
| 주소 | `https://apis.data.go.kr/1741000/StanReginCd/getStanReginCdList` | 확인함 |
| 호출 예 | `GET …/getStanReginCdList?serviceKey=<키>&type=json&pageNo=1&numOfRows=1000&sido_cd=28` | 확인함 |
| `numOfRows` | 1000까지 | 확인함 |
| 필터 | `sido_cd` · `sgg_cd` · `locatadd_nm`만 동작. `region_cd`는 필터가 **아님** | 확인함 |
| 이력 | 과거 코드·폐지 이력 없음(현행 코드만) | 확인함 |
| 이용허락 | 확인하지 못함 | — |

`region_cd`는 10자리이며 구성은 **시도 2 + 시군구 3 + 읍면동 3 + 리 2**입니다.

| 층 | 행 수 |
|---|---|
| 시도 | 15 |
| 시군구 | 269 |
| 읍면동 | 5,067 |
| 리 | 15,209 |
| 합계 | 20,560 |

전국을 한 번에 받으면 1000행씩 21쪽입니다(계산값). 개편이 있어도 과거 코드가 표에 남지 않으므로, 개편 전 코드를 입력하면 "표에 없음"으로 나옵니다.

### 1.2 최근 개편

| 개편 | 적용일 | 내용 | 확인 |
|---|---|---|---|
| 전남광주통합특별시 | 2026-07-01 | 시도 코드 12 | 확인함. 번들 `region.json`의 광산구 `12330`·나주시 `12170`은 12로 시작하고, `resolve` 실호출로 두 코드(와 법정동 8자리 `12330106` 운수동·`12170134` 빛가람동)가 표에 있음을 확인함(2026-10-05) |
| 인천 구 신설 | 2026-07-01 | 제물포구 `28125` · 영종구 `28155` · 서해구 `28275` · 검단구 `28290` 신설 | 확인함. 계양구(`28245`)의 읍면동 23곳은 V-World와 표준코드가 일치(1.3) |

### 1.3 파생식과 검증

| # | 파생식 | 검증 대상 | 결과 | 확인 방법 |
|---|---|---|---|---|
| 1 | V-World `sig_cd` = `region_cd` 앞 5자리 | 인천 시군구 11 · 전남광주 시군구 27 | 집합이 표준코드와 **완전히 같음** | V-World 시군구 경계 속성 vs 표 |
| 2 | V-World `emd_cd` = `region_cd` 앞 8자리 | 계양 읍면동 23 · 광산구 79 · 나주 47 | 집합이 표준코드와 **완전히 같음** | V-World 읍면동 경계 속성 vs 표 |
| 3 | 건축HUB `sigunguCd` = 앞 5자리, `bjdongCd` = 6~10자리 | 성북구 `11290` + 장위동 `13800` = `1129013800` | 주택인허가 기본개요 89건 재현(4.1) | 건축HUB 직접 호출 |
| 4 | PNU 19 = 법정동 10 + 대지구분 1 + 본번 4 + 부번 4 | PNU 샘플 3건(계양구 박촌동 177 포함) | 앞 10자리가 법정동코드와 일치. 대지구분 `1`(일반)은 `resolve`가 필지 경계를 돌려줘 확인함. 샘플이 적어 일반화는 추정 | V-World 필지 속성 |
| 5 | 8자리 → 10자리: 끝에 `00` 보충 | `emd_cd` 8자리 → `region_cd` 읍면동 단위(리 `00`) | 식 2와 같은 집합 | 표 대조 |

- V-World는 `emd_cd` · `sig_cd` · `pnu` 속성 조회로 경계와 필지를 줍니다. 건물 레이어는 `pnu`로 거를 수 없어 **필지 폴리곤과 공간 교차**로 잇습니다(확인함).
- V-World에서 리(里) 단위 경계 레이어는 확인하지 못함. 리 코드는 읍면동 경계로 표시하는 후퇴를 둡니다(스펙 1.4).
- 같은 10자리인 법정동코드와 행정동코드(행정기관코드)가 서로 겹치는지는 확인하지 못함. 같은 8자리인 V-World `emd_cd`와 통계청 8자리 분류코드가 겹치는지도 확인하지 못함. 그래서 스펙은 **표 존재 검증을 판별의 마지막 근거**로 둡니다.

### 1.4 결정에 준 영향

| 사실 | 결정·규칙 |
|---|---|
| 표준코드와 V-World·건축HUB·PNU가 모두 앞 자리에서 파생됨 | 정본은 법정동 10자리 하나, 나머지는 자르거나 보충해서 만든다(결정 3) |
| `emd_cd` 8자리 = 앞 8자리 | 8자리 입력을 `00` 보충으로 받는다 |
| 개편 코드는 표에 과거가 없음 | 과거 코드는 `unknown-code`(404). 상위 코드로 후퇴하는 것은 제안이며 지금은 하지 않음 |
| `region_cd`가 필터가 아님 | 시군구 단위(`sido_cd`+`sgg_cd`)로 받아 로컬 캐시(24시간)에서 찾는다(구현됨) |

## 2. 법정동↔행정동 연계

법정동↔행정동은 **다대다**입니다. 한 행정동이 여러 법정동을 포함하고, 한 법정동이 여러 행정동에 걸칩니다. 그래서 행정동 입력은 **법정동 집합**으로 바꿔 씁니다. 행정동 경계 폴리곤은 V-World 법정읍면동(ADEMD)으로 얻을 수 없고, 행정동 경계 레이어는 확인하지 못했습니다.

### 4.6 판정

세 방안을 같은 기준으로 비교합니다. **판정 기준은 제안이므로 조정할 수 있습니다.**

- A: 건축HUB 관리번호를 사업 id로 직접 사용
- B: 발급형 내부 id + 외부 참조키(`refs`)로 보관
- C: 지구명을 id에 넣는 안(`{시군구}-{지구}-{블록}`)

| 기준 | 구분 | A 관리번호 직접 | B 내부 id + refs | C 지구명 id | 근거 |
|---|---|---|---|---|---|
| 유일성 | 필수 | △ | ○ | △ | A: 서비스 안 89/89 고유이나 서비스 간 이름공간이 다름. C: 지구 코드가 표준에 없음 |
| 사업 단위 1:1 | 필수 | × | ○ | △ | A: 같은 대지 23곳 중 9곳에 관리번호 2개 이상. C: 블록 단위가 사업과 다를 수 있음(추정) |
| 인허가 전 단계 커버 | 필수 | × | ○ | ○ | A: 장위14구역은 키가 없음 |
| 이용허락 | 필수 | △ | ○ | ○ | A: 포털 이용허락은 '제한 없음'이나 약관에 복제·제공 제한 문구가 있어 어긋남(신청API정리 문서 기록, 제공기관 확인 필요). B: 식별자를 참조로만 보관하고 원천 응답은 재배포하지 않음 |
| 형식 일관성 | 권장 | × | ○ | △ | A: 6·7·13·22자리 혼재 |
| 안정성 | 권장 | △ | ○ | × | A: 변경허가마다 새 기록, 재발급 여부 확인하지 못함. C: 지구 이름이 바뀔 수 있음 |
| 서비스 간 호환 | 권장 | × | ○ | △ | A: 주택·건축인허가 키 겹침 0, 필드 이름도 다름. B: `refs`에 여러 서비스 키를 함께 보관 |
| 의미 부여 | 권장 | × | △ | ○ | A: 일련번호라 의미 없음. B: 시군구 5자리만 의미 |

**판정 규칙(제안)**: 필수 기준에 × 하나라도 있으면 **불허**. 필수에 ×가 없고 권장에도 ×가 없으면 **허용**. 필수에 ×가 없으나 권장에 ×가 있으면 **비권장**.

| 방안 | 필수 × | 권장 × | 판정 |
|---|---|---|---|
| A 관리번호 직접 사용 | 2 | 3 | **불허** |
| B 내부 id + refs | 0 | 0 | **허용** |
| C 지구명 id | 0 | 1 | **비권장** |

### 4.7 권장 id 형식

| 항목 | 내용 |
|---|---|
| 형식 | `PRJ-{시군구5}-{일련4}` 예 `PRJ-28245-0003` |
| 일련 | 시군구 안에서 `0001`부터 발급(최대 9,999) |
| 시군구 | **발급 시점**의 시군구. 이후 행정구역이 바뀌어도 id는 불변이고 현재 시군구는 `sgg` 속성이 정본(인천 구 신설이 실제 사례) |
| 참조키 | 건축HUB 관리번호 등은 `refs`에 **문자열**로 보관: `{ system: "hub-hs-basis", key: "mgmHsrgstPk", value: "…" }` |
| 병합·분할 | 폐기된 id는 `supersededBy`로 승계를 남긴다(제안) |
| 미정 | 발급 주체·시점·절차, 수작업 입력 사업의 id 발급은 합의 필요 |
