- 키: `.env.local` 의 `DATA_GO_KR_KEY`(공공데이터포털) · `VWORLD_DEV_KEY`(로컬은 이 키 + domain localhost) · `HUG_SERVICE_KEY`(HUG, 1년마다 갱신, 2027-10-12 까지). 키 값은 어떤 파일·manifest 에도 남기지 않았다(새 폴더 전체를 grep 으로 확인).
- 개발계정 일일 한도: 청약홈 40,000 · K-apt 5,000 · 마이홈 1,000 · LH 10,000. HUG 는 한도 안내 없음.

## 4. 저장 규칙

- 100 MB 를 넘는 대용량 zip(`hub-bulk-ap`·`hub-bulk-bld`)과 API 원본 응답(청약홈·경쟁률·V-World·K-apt·마이홈·LH·HUG·공고 상세)은 `.gitignore` 에 넣어 `manifest.json` 만 추적한다. API 원본은 기획서 결정 4 "원천 응답 재배포 안 함"을 따른다. 작은 공공 파일(CSV·xlsx)은 기존 raw 폴더처럼 저장소에 둔다.
- 이번 수집으로 `raw/` 는 약 1.7 GB 다(기존 건축HUB 원본 포함). 다른 곳에서 다시 쓰려면 `tools/ledger/raw-store.js` 로 Storage `ledger-raw/` 에 올리는 것을 정해야 한다(아직 안 함).

## 5. 원장 반영 (2026-10-13)

중간 스냅샷 `snapshot/stage-2026-08.json`(`tools/ledger/stage-snapshot.js`, 수동 단계)을 `convert.js --stage` 로 원장 16표에 더했다. 규칙은 `tools/ledger/stage-link.js` 하나이고, 2026-10-12 측정에서 표본 정밀도 95% 이상인 자동 규칙만 쓴다. 행을 더하기만 한다(사업·기관은 그대로). 사업 단계(stage_code)는 변환 마지막에 원천을 가리지 않고 실제 이벤트로 올린다(아래 '후속'). 자동 연결이라 이벤트·연결·식별자는 REVIEW_REQUIRED. 판정 이력의 소급 달은 단계별 원천을 쓰지 않는다.
