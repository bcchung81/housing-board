#### regions.csv (필수 파일)

지역(시군구) 1행. 폴더 이름과 region_slug가 같아야 한다.

| 열 | 필수 | 형식 | 설명 |
|---|---|---|---|
| `region_slug` | ● | slug(소문자·숫자·하이픈) | 지역 식별자. 폴더 이름과 같아야 함. 예: gwangju-gwangsan |
| `region_name` | ● | 문자 | 화면에 표시할 이름. 예: 광주 광산구 |
| `sido_name` |  | 문자 | 예: 광주광역시 |
| `sigungu_name` |  | 문자 | 예: 광산구 |
| `center_lon` |  | 경도 124~132 | 시작 지도 중심 경도. 비우면 지구 경계에서 계산 |
| `center_lat` |  | 위도 33~39 | 시작 지도 중심 위도. 비우면 지구 경계에서 계산 |
| `default_zoom` |  | 숫자 8~18 | 시작 확대 수준. 비우면 자동 |
| `note` |  | 문자 | 메모 |

기본키: `region_slug`

단지(블록) 1행. 시행자 유형은 시행자를 직접 말하는 자료(공고문·공사현황·공급기관명)로 정한다.

| 열 | 필수 | 형식 | 설명 |

| `zone_id` |  | slug(소문자·숫자·하이픈) | 소속 지구. 지구 밖 단지는 비움 |
| `project_name` | ● | 문자 | 공고·공사현황의 이름. 예: 광주선운2 A-1블록 신혼희망타운 |
| `block_label` | ● | 문자 | 지도에 짧게 보일 이름. 예: A-1 |
| `block_name_raw` |  | 문자 | 출처 원문 블록 이름. 예: A-1BL. 매칭에 쓰인다 |
| `sponsor_name` | ● | 문자 | 시행자 이름. 예: LH |
| `sponsor_type` | ● | 열거 (sponsor_type) | 시행자 유형. public 공공, private 민간, joint 민관 공동, unknown 미확인 |
| `project_kind` | ● | 열거 (project_kind) | 사업 유형 |
| `on_public_land` |  | 열거 (on_public_land) | 공공택지 위 여부. 비우면 지구 유형으로 계산 |
| `units` |  | 정수 0~ | 총 세대수. 모르면 비움 |

| `pnu_list` |  | 19자리 숫자 목록(;로 구분) | 필지 번호(PNU) 19자리 목록, 세미콜론(;)으로 구분. 윤곽·블록 매칭의 1순위 키 |
| `address` |  | 문자 | 주소 |
| `source_id` | ● | slug(소문자·숫자·하이픈) | 이 행의 근거 출처 |
| `observed_at` | ● | 날짜 YYYY-MM-DD | 수집한 날 |
| `verified` |  | Y/N | 사람이 원문으로 확인했으면 Y |
| `note` |  | 문자 | 메모 |
